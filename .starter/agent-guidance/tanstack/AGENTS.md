# TanStack Start workspace

Read the repository-level `AGENTS.md` before changing this workspace.

- Keep routes under `src/routes` and feature code under `src/features`.
- Use server functions for server-only work and keep secrets out of client bundles.
- Treat `src/routeTree.gen.ts` as generated output. Change route source files instead.
- Run this workspace's `typecheck` and relevant tests after changes.
